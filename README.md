## Área administrativa
Toque/click na logo `C` do cabeçalho 5 vezes rapidamente para abrir a área de gestão.

A área permite alterar nome, OAB, WhatsApp, e-mail, endereço, título principal, mensagem inicial do WhatsApp, imagem principal e logo.

As alterações são salvas em `localStorage` deste navegador/dispositivo. Isto é adequado para uma landing page estática de demonstração; não é uma autenticação de servidor. Para uso público com segurança real, a gestão deve ser ligada a backend/autenticação.
